## Bubble Sort

Description: A simple comparison-based sorting algorithm. It repeatedly swaps adjacent elements if they are in the wrong order.
`Time Complexity:`
Best Case: O(n) (when the array is already sorted)
Worst Case: O(n²)
Space Complexity: O(1)

## Insertion Sort

Description: Builds the sorted array one element at a time by inserting each element into its correct position.
`Time Complexity:`
Best Case: O(n) (when the array is already sorted)
Worst Case: O(n²)
Space Complexity: O(1)

## Merge Sort

Description: A divide-and-conquer algorithm that splits the array into smaller subarrays, sorts them recursively, and merges them back into a sorted array.
`Time Complexity:`
Best Case: O(n log n)
Worst Case: O(n log n)
Space Complexity: O(n) (due to auxiliary arrays)

## Selection Sort

Description: Repeatedly selects the smallest (or largest) element from the unsorted part of the array and places it in its correct position.
`Time Complexity:`
Best Case: O(n²)
Worst Case: O(n²)
Space Complexity: O(1)
